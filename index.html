About Me

Multimedia Computing student at UiTM Shah Alam and a developer who turns ideas into working software. I'm especially drawn to web development, machine learning, data analytics and game development with hands-on work in Python, scikit-learn, OpenCV, SQL and Unity. Alongside that, I build across full-stack web (PHP, JavaScript, MySQL), Flutter mobile apps and Unity games. I'm open to software engineering, web development, mobile development, machine learning or any CS related internships where I can ship real features, learn fast and find where I can grow the most.
